## 1. 设计原则

### 1.1 核心原则

| 原则 | 含义 | 实践 |
|------|------|------|
| **效率优先** | B 端广告优化师需要快速完成操作 | 减少点击层级，关键操作不超过 3 步 |
| **信息密度适中** | 展示足够信息但不过载 | 任务卡片仅展示核心三要素（名称、状态、结果） |
| **状态透明** | 用户始终知道系统在做什么 | 连接状态、任务进度、Agent 思考过程全部可见 |
| **容错友好** | 关键操作有确认，错误可恢复 | dry-run/test-run 双重确认机制 |
| **渐进披露** | 复杂信息按需展开 | 任务时间线可折叠，详情分层展示 |

### 1.2 设计气质

- **专业**：面向 B 端广告优化师，不花哨，不卡通
- **可信赖**：状态清晰，操作可预期，无隐藏行为
- **高效**：飞书级交互效率，键盘友好，即时反馈
- **克制**：色彩仅在状态指示时使用，避免装饰性元素

## 2. 设计语言

### 2.1 色彩系统

#### 语义色

| 语义 | 变量 | 色值 | 使用场景 |
|------|------|------|----------|
| 主色 | `--color-primary` | `#409EFF` | 按钮、链接、选中态、聚焦态 |
| 成功 | `--color-success` | `#67C23A` | 已完成、已授权、在线 |
| 警告 | `--color-warning` | `#E6A23C` | 运行中、需注意、连接中 |
| 危险 | `--color-danger` | `#F56C6C` | 失败、错误、登出、删除 |

#### 中性色

| 用途 | 变量 | 色值 |
|------|------|------|
| 文字主色 | `--admiral-text-primary` | `#303133` |
| 文字次色 | `--admiral-text-secondary` | `#606266` |
| 占位/弱化 | `--admiral-text-placeholder` | `#909399` |
| 边框 | `--admiral-border` | `#DCDFE6` |
| 页面底色 | `--admiral-bg` | `#F5F7FA` |
| 卡片背景 | `--admiral-card` | `#FFFFFF` |

#### 色彩使用规则

1. **主色**仅用于可交互元素（按钮、链接、选中态），不用于装饰
2. **语义色**仅用于状态指示，不用于背景大面积铺色
3. 悬停态使用 `opacity: 0.9` 或对应色的 10% 透明度背景
4. 禁用态使用 `opacity: 0.5` + `cursor: not-allowed`

### 2.2 圆角体系

| 层级 | 变量 | 值 | 使用场景 |
|------|------|-----|----------|
| 大圆角 | `--admiral-radius-card` | `8px` | 卡片、面板、弹窗 |
| 中圆角 | `--admiral-radius-button` | `6px` | 按钮、下拉菜单 |
| 小圆角 | `--admiral-radius-input` | `4px` | 输入框、标签 |
| 圆形 | — | `50%` | 状态指示点、头像 |

### 2.3 阴影体系

| 层级 | 变量/值 | 使用场景 |
|------|---------|----------|
| 卡片阴影 | `--admiral-shadow-card`: `0 1px 3px rgba(0,0,0,0.06)` | 卡片、Header |
| 浮层阴影 | `0 4px 12px rgba(0,0,0,0.1)` | 下拉菜单、弹窗 |
| 拖拽阴影 | `0 8px 24px rgba(0,0,0,0.15)` | 拖拽中的元素 |

### 2.4 字体规范

| 属性 | 值 |
|------|-----|
| 字体栈 | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` |
| 基础字号 | `14px` |
| 行高 | `1.5`（正文），`1.3`（标题） |
| 标题权重 | `600` |
| 正文权重 | `400` |
| 辅助权重 | `500` |

#### 文字层级

| 层级 | 字号 | 权重 | 颜色 | 场景 |
|------|------|------|------|------|
| H1 | 18px | 600 | text-primary | 页面大标题 |
| H2 | 16px | 600 | text-primary | 区域标题（任务名称） |
| H3 | 14px | 600 | text-primary | 卡片标题 |
| Body | 14px | 400 | text-primary | 正文内容 |
| Caption | 12px | 400 | text-secondary | 辅助说明、时间戳 |
| Overline | 11px | 500 | text-placeholder | 标签、分类名 |

### 2.5 间距系统

采用 4px 基础网格：

| 级别 | 值 | 场景 |
|------|-----|------|
| xs | 4px | 元素间微间距（状态点与文字） |
| sm | 8px | 组件内部间距、列表项间距 |
| md | 12px | 卡片内边距 |
| lg | 16px | 区域间距、页面边距 |
| xl | 24px | 大区域分隔 |
| 2xl | 32px | 页面级分隔 |

## 4. 导航体系

### 4.1 导航层级

```
一级导航：LeftTab（媒体账户 / 任务 / 能力栏）
  └── 二级导航：主区域内容切换
      ├── 任务 → TaskList + TaskDetail
      ├── 媒体账户 → 跳转 /settings/platforms
      └── 能力栏 → Skill 列表（Phase 5）

辅助导航：Header 右侧
  ├── 账户下拉 → 用户信息 / 登出
  └── 设置齿轮 → /settings
```

### 4.2 LeftTab 交互规范

#### 展开状态（220px）

```
┌──────────────────────┐
│ [📺] 媒体账户          │  ← 图标 + 文字 + 子状态
│       B站 已授权 ✓     │
│                      │
│ [📋] 任务         ← 选中│  ← 选中态：左侧蓝色指示条 + 浅蓝背景
│                      │
│ [⚡] 能力栏 (灰)       │  ← 禁用态：降低透明度
│                      │
│ ··· 剩余空间 ···       │
│                      │
│      [◀ 收起]         │  ← 底部折叠按钮
└──────────────────────┘
```

#### 折叠状态（56px）

```
┌──────┐
│ [📺] │  ← 仅图标，hover 显示 Tooltip
│      │
│ [📋] │  ← 选中态：蓝色背景圆角矩形
│      │
│ [⚡] │
│      │
│ [▶]  │  ← 展开按钮
└──────┘
```

#### 交互行为

| 动作 | 行为 | 过渡 |
|------|------|------|
| 点击 Tab 项 | 切换 `activeTab`，更新主区域内容 | 无额外动画，内容即时切换 |
| 点击「媒体账户」 | 跳转 `/settings/platforms` | 路由切换 |
| 点击「任务」 | 回到 `/`，展示任务列表+详情 | 路由切换 |
| 点击折叠/展开 | 宽度在 56px ↔ 220px 之间过渡 | `transition: width 0.2s ease` |
| Hover Tab 项（折叠时） | 显示 Tooltip（文字标签） | 延迟 300ms 出现，移开立即消失 |
| 键盘：Tab 键 | 焦点在 Tab 项之间移动 | 显示 focus ring |

#### 选中态样式

```css
/* 选中 */
background-color: rgba(64, 158, 255, 0.1);
color: var(--color-primary);

/* 悬停（未选中） */
background-color: rgba(0, 0, 0, 0.04);

/* 禁用 */
opacity: 0.6;
cursor: not-allowed;
```

#### 交互行为

| 交互 | 行为 |
|------|------|
| Tab 切换「登录/注册」 | 切换表单，注册时显示邀请码字段；Tab 有下划线指示 |
| 输入验证 | 邮箱格式实时校验，密码最小 6 位，失焦时校验 |
| 提交表单 | Enter 键或点击按钮提交；按钮进入 loading 态 |
| 登录成功 | 跳转 `/`，加载用户信息和 License |
| 登录失败 | 输入框下方显示红色错误提示，抖动效果（shake） |
| 注册成功 | 自动登录并跳转 `/` |
| 邀请码无效 | 邀请码输入框标红，提示「邀请码无效或已过期」 |

#### 输入框规范

- 聚焦时：`border-color: var(--color-primary)` + `ring-2 ring-primary/30`
- 错误时：`border-color: var(--color-danger)` + 下方显示错误文字
- 禁用时：`opacity: 0.5` + `cursor: not-allowed`
- 密码输入框：右侧可选 eye icon 切换显示/隐藏

## 8. 动效与过渡

### 8.1 动效原则

1. **有意义**：动效传达信息（展开/折叠暗示内容变化），非装饰
2. **快速**：绝大多数过渡 150–250ms，不超过 300ms
3. **自然**：使用 `ease` 或 `ease-out` 缓动，避免线性运动
4. **可关闭**：尊重 `prefers-reduced-motion` 系统偏好

### 8.2 标准过渡时长

| 场景 | 时长 | 缓动 |
|------|------|------|
| 颜色变化（hover/focus） | 150ms | ease |
| 展开/折叠（LeftTab） | 200ms | ease |
| 弹窗进入 | 200ms | ease-out |
| 弹窗退出 | 150ms | ease-in |
| Toast 进入 | 250ms | ease-out |
| Toast 退出 | 200ms | ease-in |
| 页面路由切换 | 0ms | 即时（不加转场） |

### 8.3 关键动效

| 动效 | 实现 | 触发 |
|------|------|------|
| **LeftTab 折叠** | `width` 220px ↔ 56px，200ms ease | 点击折叠按钮 |
| **按钮按下** | `transform: scale(0.98)` | mousedown |
| **卡片悬停** | `translateY(-2px)` + 阴影加深 | 设置卡片 hover |
| **状态点脉冲** | `scale(1)→scale(1.5)→scale(1)` + opacity，2s 循环 | 运行中状态 |
| **进度条流动** | 条纹 `@keyframes` 从右到左 | 运行中 |
| **Skeleton 扫光** | 渐变从左到右移动，1.5s 循环 | 加载中 |
| **Agent 打字光标** | 竖线 opacity 0↔1，500ms 循环 | Agent 流式输出中 |
| **消息出现** | `translateY(8px)→translateY(0)` + `opacity 0→1`，200ms | 新消息 |
| **输入框增高** | `height` 自动过渡 | 输入内容增多 |

### 8.4 `prefers-reduced-motion` 适配

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 11. 响应式与窗口适配

### 11.1 窗口尺寸策略

Admiral 是 Tauri 桌面应用，不需要完整的移动端响应式，但需要适配不同窗口尺寸：

| 窗口宽度 | 适配策略 |
|----------|----------|
| ≥ 1280px | 标准三栏：LeftTab(220px) + TaskList(300px) + Detail(flex) |
| 1024–1279px | LeftTab 自动折叠(56px) + TaskList(280px) + Detail(flex) |
| < 1024px | 不建议，但 Tauri min-width 可设 1024px |

### 11.2 拖拽分栏

TaskList 栏和 TaskDetail 栏之间的分隔线支持拖拽调整宽度：

| 属性 | 值 |
|------|-----|
| 分隔线宽度 | 4px（实际可拖拽区域 8px，包含透明扩展区） |
| 分隔线样式 | 透明，hover 时显示灰色线 |
| 拖拽光标 | `cursor: col-resize` |
| TaskList 最小宽度 | 240px |
| TaskList 最大宽度 | 400px |
| Detail 最小宽度 | 480px |
| 拖拽反馈 | 拖拽时分隔线变为蓝色 |

### 11.3 内容溢出策略

| 区域 | 溢出处理 |
|------|----------|
| TaskList | 纵向滚动，横向截断 |
| TaskDetail 展示区 | 纵向滚动 |
| ChatPanel 消息区 | 纵向滚动，新消息自动滚到底 |
| ChatInput | 纵向自动增高至 max-height，再出现滚动条 |
| 任务名称 | 单行截断 `text-overflow: ellipsis` |
| 用户邮箱 | 最大 140px，截断 |

## 12. 用户流程详解

### 12.1 首次使用流程

```
启动应用
    │
    ├── 无 Token → 跳转 /login
    │       │
    │       ├── 有邀请码 → 注册 → 自动登录 → 进入主页
    │       └── 已有账户 → 登录 → 进入主页
    │
    └── 有 Token → 校验 Token
            │
            ├── 有效 → 加载用户信息 → 进入主页
            └── 过期 → 尝试 Refresh
                    │
                    ├── 成功 → 进入主页
                    └── 失败 → 跳转 /login
```

### 12.2 创建并执行任务流程

```
主页 → 点击「+ 新建任务」
    │
    ├── Step 1: 输入任务名称
    ├── Step 2: 选择任务类型（即时/定时）
    ├── Step 3: 确认并创建
    │
    └── 创建成功 → 自动选中新任务
            │
            ├── 在输入框输入自然语言指令
            │   「帮我优化 B 站广告出价，CTR 低于 2% 的降低出价 10%」
            │
            ├── Agent 解析 → 生成执行计划 → 自动 Dry Run
            │       │
            │       └── 展示执行时间线（各步骤推进）
            │
            ├── Dry Run 完成 → 展示变更预览 + 确认区块
            │       │
            │       ├── 确认 → 开始 Test Run
            │       └── 取消 → 回到 draft
            │
            ├── Test Run 完成 → 展示测试结果 + 确认区块
            │       │
            │       ├── 确认部署 → 任务上线执行
            │       └── 取消 → 回到 draft
            │
            └── 执行完成 → 展示结果摘要
```

### 12.3 平台授权流程

```
LeftTab 点击「媒体账户」 → 跳转 /settings/platforms
    │
    ├── 未授权 → 点击「发起授权」
    │       │
    │       ├── 系统打开浏览器 B 站 OAuth 页面
    │       ├── 客户端显示「等待授权完成…」
    │       ├── 轮询检查授权状态
    │       │       │
    │       │       ├── 成功 → 刷新页面，展示已授权态
    │       │       └── 超时 → 提示重试
    │       │
    │       └── 授权成功后 → 加载广告账户列表
    │               │
    │               ├── 勾选要绑定的账户
    │               └── 点击「绑定」→ 完成
    │
    └── 已授权 → 管理已绑定账户
            │
            ├── 绑定新账户：勾选 + 确认
            ├── 解绑账户：取消勾选 + 确认
            └── 取消授权：确认弹窗 → 删除 Session
```

### 12.4 Agent 对话流程

```
用户在 ChatInput 输入消息 → 点击发送 / Enter
    │
    ├── 消息出现在 ChatPanel（user 气泡，右对齐）
    │
    ├── 展示「Admiral 正在思考…」（三点动画）
    │
    ├── Agent 回复（流式输出）
    │       │
    │       ├── 文字逐步出现 + 闪烁光标
    │       └── 输出完成 → 光标消失
    │
    ├── 若需确认操作 → 展示 ConfirmActions
    │       │
    │       ├── 用户确认 → 继续执行
    │       └── 用户取消 → Agent 回复「已取消」
    │
    └── 消息区自动滚动到最新消息
```
