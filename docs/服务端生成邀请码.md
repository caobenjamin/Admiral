# 服务端生成邀请码

服务端通过 **Admin API** 生成邀请码，需要**已登录且角色为 admin** 的账号。

**说明**：本仓库采用「服务端在远端运行」的联调模式。以下操作在**远端服务器**上执行（如数据库插入），或通过 curl 访问**远端 API**（如登录、生成邀请码）。

---

## 零、首次创建 admin 账号（用户表为空时）

若 `users` 表里还没有任何用户，需要先「手动插入一条邀请码 → 用该码注册第一个用户 → 再将该用户设为 admin」。

### 第一步：在数据库里插入一条 bootstrap 邀请码

在服务器上执行（插入邀请码 `INV-BOOTSTRAP`，试用 7 天、可用 1 次）：

```bash
sudo -u postgres psql -d admiral -c "
INSERT INTO invites (id, code, trial_days, max_uses, used_count, created_by, expires_at, created_at)
VALUES (
  gen_random_uuid(),
  'INV-BOOTSTRAP',
  7,
  1,
  0,
  NULL,
  NULL,
  NOW()
);
"
```

### 第二步：用接口注册第一个用户

在本机或服务器上执行（将邮箱、密码、名字换成你的）：

```bash
curl -s -X POST https://admiral.example.com/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@example.com",
    "password": "CHANGE_ME_ADMIN_PASSWORD",
    "name": "ben",
    "invite_code": "INV-BOOTSTRAP"
  }'
```

成功会返回带 `access_token` 的 JSON。

### 第三步：把该用户设为 admin

在服务器上执行（将邮箱换成你刚注册的邮箱）：

```bash
sudo -u postgres psql -d admiral -c "UPDATE users SET role = 'admin' WHERE email = '你的邮箱';"
```

验证：

```bash
sudo -u postgres psql -d admiral -c "SELECT id, email, name, role, status, created_at FROM users ORDER BY created_at DESC;"
```

应能看到该用户且 `role = admin`。之后即可用此账号登录，并按下面步骤生成邀请码。

---

## 一、确保有 admin 账号（已有用户时）

接口要求当前用户 `role = admin`。若**已有用户**、只需把某人提为 admin：

在服务器上执行：

```bash
sudo -u postgres psql -d admiral -c "UPDATE users SET role = 'admin' WHERE email = '你的邮箱';"
```

---

## 二、用 Admin 账号拿到 Token

用 admin 账号调登录接口拿到 `access_token`：

```bash
curl -s -X POST https://admiral.example.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"你的admin邮箱","password":"密码"}'
```

响应里会有 `access_token`，后面请求都要带上它。

---

## 三、生成新邀请码

**接口**：`POST /api/v1/admin/invites`  
**鉴权**：`Authorization: Bearer <access_token>`

**请求体（JSON，均可选）**：

| 字段          | 说明                 | 默认值   |
|---------------|----------------------|----------|
| `trial_days`  | 试用天数             | 7        |
| `max_uses`    | 该码最多使用次数     | 1        |
| `expires_at`  | 邀请码过期时间（RFC3339） | 无过期 |

### 示例：生成一个 7 天试用、只能用 1 次的邀请码

```bash
curl -s -X POST https://admiral.example.com/api/v1/admin/invites \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的access_token" \
  -d '{}'
```

### 示例：自定义试用天数和可用次数

```bash
curl -s -X POST https://admiral.example.com/api/v1/admin/invites \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的access_token" \
  -d '{"trial_days": 30, "max_uses": 5}'
```

### 示例：带过期时间（RFC3339）

```bash
curl -s -X POST https://admiral.example.com/api/v1/admin/invites \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的access_token" \
  -d '{"trial_days": 7, "max_uses": 1, "expires_at": "2026-03-31T23:59:59Z"}'
```

成功时返回 **201**，响应体里会包含新邀请码，例如：

```json
{
  "id": "uuid",
  "code": "INV-A1B2C3D4",
  "trial_days": 7,
  "max_uses": 1,
  "used_count": 0,
  "expires_at": null,
  "created_at": "2026-02-19T..."
}
```

把其中的 **`code`**（如 `INV-A1B2C3D4`）发给用户，注册时填写该邀请码即可。

---

## 四、查看已有邀请码（可选）

```bash
curl -s https://admiral.example.com/api/v1/admin/invites \
  -H "Authorization: Bearer 你的access_token"
```

返回所有邀请码列表（含 code、使用次数等）。

---

## 小结

| 操作     | 方法 | 路径                          |
|----------|------|-------------------------------|
| 生成邀请码 | POST | `/api/v1/admin/invites`       |
| 列出邀请码 | GET  | `/api/v1/admin/invites`       |

生成新邀请码 = 用 admin 的 token 调 `POST /api/v1/admin/invites`，按需传 `trial_days`、`max_uses`、`expires_at`，响应里的 `code` 即为新邀请码。
