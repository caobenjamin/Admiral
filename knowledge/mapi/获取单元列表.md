## 接口名称：获取单元列表

### 接口信息
- **请求地址**：`https://cm.bilibili.com/takumi/api/open_api/cpc/v3/unit/list_units`
- **接口描述**：此接口用于批量查询账户下新三连单元详情信息，包括单元名称、状态、推广内容、定向及出价等信息
- **请求方法**：GET

### 公共参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| account_id | integer | 是 | 广告主账户ID |

### 请求参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| campaign_ids | string | 否 | 计划ID列表（最多100个） |
| unit_ids | string| 否 | 单元ID列表（最多100个） |
| unit_status | string | 否 | 单元状态过滤，多选请使用逗号分隔符连接：<br>1-有效，2-已暂停，3-已结束, 4-已删除, 5-未开始, 6-预算超限, 7-不在投放时段, 8-已完成 ，默认不限|
| start_ctime | integer | 否 | 单元创建时间开始（时间戳，毫秒） |
| end_ctime | integer | 否 | 单元创建时间结束（时间戳，毫秒）<br>起止时间跨度不超过24小时 |
| start_mtime | integer | 否 | 单元更新时间开始（时间戳，毫秒） |
| end_mtime | integer | 否 | 单元更新时间结束（时间戳，毫秒）<br>起止时间跨度不超过24小时 |
| page | integer | 否 | 页码（默认1） |
| size | integer | 否 | 每页数量（默认10，范围1-100） |

### 请求示例
```bash
curl --location --request GET \
  'https://cm.bilibili.com/takumi/api/open_api/cpc/v3/unit/list_units' \
  -H 'Authorization: Bearer YOUR_YOUR_ACCESS_TOKEN' \
  --get \
  --data-urlencode 'account_id=your_account_id' \
  --data-urlencode 'campaign_ids=15695752,15654284' \
  --data-urlencode 'unit_status=1,2' \
  --data-urlencode 'page=1' \
  --data-urlencode 'size=100'
```
