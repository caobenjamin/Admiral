
## 接口名称：获取创意列表

### 接口信息
- **请求地址**：`https://cm.bilibili.com/takumi/api/open_api/cpc/v3/creative/list_creatives`
- **接口描述**：此接口用于批量查询账户下新三连创意详情信息，包括创意名称、状态、审核状态及反馈、素材、落地页、监测链接等信息
- **请求方法**：GET

### 公共参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| account_id | integer | 是 | 广告主账户ID |

### 请求参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| campaign_ids | string | 否 | 计划ID列表（最多100个） |
| unit_ids | string | 否 | 单元ID列表（最多100个） |
| creative_ids | string | 否 | 创意ID列表（最多100个） |
| creative_status | string | 否 | 创意状态过滤，多选请使用逗号分隔符连接：<br>1-有效，2-已暂停，3-已完成，4-已删除，5-审核中，6-审核拒绝，9-落地页审核中，默认不限； |
| start_ctime | integer | 否 | 创意创建时间开始（时间戳，毫秒） |
| end_ctime | integer | 否 | 创意创建时间结束（时间戳，毫秒）<br>起止时间跨度不超过24小时 |
| start_mtime | integer | 否 | 创意更新时间开始（时间戳，毫秒） |
| end_mtime | integer | 否 | 创意更新时间结束（时间戳，毫秒）<br>起止时间跨度不超过24小时 |
| page | integer | 否 | 页码（默认1） |
| size | integer | 否 | 每页数量（默认10，范围1-100） |

### 请求示例
```bash
curl --location --request GET \
  'https://cm.bilibili.com/takumi/api/open_api/cpc/v3/creative/list_creatives' \
  -H 'Authorization: Bearer YOUR_YOUR_ACCESS_TOKEN' \
  --data-urlencode 'account_id=your_account_id' \
  --data-urlencode 'creative_ids=15695752,15654284' \
  --data-urlencode 'start_ctime=1750694400000' \
  --data-urlencode 'end_ctime=1750780799000' \
  --data-urlencode 'creative_status=1,2' \
  --data-urlencode 'page=1' \
  --data-urlencode 'size=100'
```

### 返回参数
接口返回的数据中，仅需关注文档中明确列出的字段。
其他未在文档中说明的字段属于系统内部使用的冗余数据，开发者可以忽略这些字段。

| current_time | integer | 当前时间戳（毫秒） |
