## 接口名称：获取计划列表


### 接口信息
- **请求地址**：`https://cm.bilibili.com/takumi/api/open_api/cpc/v3/campaign/list_campaigns`
- **接口描述**：此接口用于批量查询新三连计划信息
- **请求方法**：GET

### 公共参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| account_id | integer | 是 | 广告主账户ID |

### 请求参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| campaign_ids | string | 否 | 计划ID列表（最多100个），多个请使用逗号分隔符连接 |
| campaign_status | string| 否 | 计划状态过滤，多选请使用逗号分隔符连接：<br>枚举：1-有效，2-已暂停，3-已结束，4-已删除，5-预算超限 ，默认不限；|
| start_ctime | integer | 否 | 计划创建时间开始（时间戳，毫秒） |
| end_ctime | integer | 否 | 计划创建时间结束（时间戳，毫秒），起止跨度不超过24小时； |
| start_mtime | integer | 否 | 计划更新时间开始（时间戳，毫秒） |
| end_mtime | integer | 否 | 计划更新时间结束（时间戳，毫秒），起止跨度不超过24小时； |
| page | integer | 否 | 页码（默认1） |
| size | integer | 否 | 每页数量（默认10，范围1-100） |

### 请求示例
```bash
curl --location --request GET \
  'https://cm.bilibili.com/takumi/api/open_api/cpc/v3/campaign/list_campaigns' \
  -H 'Authorization: Bearer YOUR_YOUR_ACCESS_TOKEN' \
  --get \
  --data-urlencode 'account_id=your_account_id' \
  --data-urlencode 'campaign_ids=15695752,15654284' \
  --data-urlencode 'campaign_status=1,2' \
  --data-urlencode 'page=1' \
  --data-urlencode 'size=10'
```

### 返回参数
接口返回的数据中，仅需关注文档中明确列出的字段。
其他未在文档中说明的字段属于系统内部使用的冗余数据，开发者可以忽略这些字段。

| 字段 | 类型 | 参数说明 |
|------|------|----------|
| status | string | 返回状态，"success"为成功 |
| current_time | integer | 当前时间戳（毫秒） |
| result | object ([Result](#result-字段说明)) | 返回结果 |
| error_msg | string | 具体报错信息 |
| error_code | integer | 错误码 |

#### Result 字段说明
| 字段 | 类型 | 参数说明 |
|------|------|----------|
| data | array<object> ([Campaign](#campaign-字段说明)) | 计划列表 |
| total_count | integer | 计划总数 |
| page | integer | 当前页码 |

#### Campaign 字段说明
| 字段 | 类型 | 参数说明 |
|------|------|----------|
| campaign_id | integer | 计划ID |
| campaign_name | string | 计划名称 |
| ctime | string | 创建时间（格式：yyyy-MM-dd HH:mm:ss） |
| mtime | string | 更新时间（格式：yyyy-MM-dd HH:mm:ss） |
| promotion_purpose_type | integer | 推广目的枚举：<br>120-交易经营，15-品牌传播，2-销售线索收集，4-应用推广 |
| budget | object ([Budget](#budget-字段说明)) | 预算信息 |
| campaign_status | integer | 计划状态枚举：<br>1：有效，2：已暂停，3：已结束，4：已删除，5：预算超限 |
| ad_type | integer | 计划类型：<br>枚举：0-所有广告，1-搜索广告，2-闪屏广告 |
| support_auto | integer | 是否自动投放：<br>0-手动投放，1-自动投放 |
| account_id | integer | 账户ID |
| adp_version | integer | 广告版本（6=新三连） |

#### Budget 字段说明
| 字段 | 类型 | 参数说明 |
|------|------|----------|
| budget_limit_type | integer | 预算类型枚举：<br>1-指定预算，2-不限预算，3-总预算 |
| budget | string | 预算金额（元） |
