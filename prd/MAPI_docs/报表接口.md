### 接口名称
- 自定义报表

### 接口信息
- **请求地址**：`https://cm.bilibili.com/takumi/api/open_api/report/v3/custom/query`
- **接口描述**：
  - 1、本接口用于查询自定义投放报表数据；
  - 2、支持多维度、多指标的灵活组合查询；
  - 3、支持时间维度的精细化查询（日期或小时级别）；
  - 4、本接口仅返回有消耗的数据；
  - 5、金额相关字段建议接入“_amount_milli”（毫分），精度更高；
- **请求方法**：POST
- **请求头**：
  - `Content-Type: application/json`

### 公共参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| account_id | integer | 是 | 广告主账户 ID |

### 请求参数
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| start_time | string | 是 | 开始时间，格式：yyyy-MM-DD |
| end_time | string | 是 | 结束时间，格式：yyyy-MM-DD <br>为保证查询性能、避免深分页查询，当前只支持一次调用查询1天的数据，即end_time==start_time，如果查询多日数据请分次调用 |
| dimensions | array<string> | 是 | 数据维度，详情见 ([dimensions](#dimensions-字段说明)) <br>入参时以字符串数组形式指定字段名即可 |
| metrics | array<string> | 是 | 查询指标列表,详情见 ([Metrics](#metrics-字段说明))   |
| filters | array<object> ([Filters](#filters-字段说明)) | 是 | 过滤条件，支持多个过滤对象 <br>如果不设置过滤条件请填写空数组`[]` |
| order_by | array<object>  ([OrderBy](#orderby-字段说明)) | 是 | 排序条件，必传、且只允许传一个排序对象<br>排序字段必须为`metrics`的字段之一  |
| page | integer | 是 | 页码，默认为1 |
| size | integer | 是 | 每页数量，最大支持100 |

#### Filters 字段说明
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| field | string | 是 | 过滤字段名,支持的枚举值：`campaign_id` `unit_id` `creative_id`  |
| values | array<string> | 是 | 过滤值列表 |

#### OrderBy 字段说明
| 字段 | 类型 | 必填 | 参数说明 |
|------|------|------|----------|
| field | string | 是 | 排序字段名 <br>排序的内容，必须在`metrics`中被指定 |
| type | string | 是 | 排序类型，1:升序 2:降序 |

### 请求示例
```bash
curl --location --request POST \
  'https://cm.bilibili.com/takumi/api/open_api/report/v3/custom/query' \
  --header 'Authorization: Bearer YOUR_YOUR_ACCESS_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "account_id": 1234,
    "start_time": "2025-06-01",
    "end_time": "2025-06-01",
    "dimensions": [
        "date_time",
        "account_id",
        "campaign_id"
    ],
    "metrics": [
        "show_count",
        "click_count",
        "charged_cost_milli"
    ],
    "filters": [
        {
            "field": "campaign_id",
            "values": [
                "13491879"
            ]
        }
    ],
    "order_by": [
        {
            "field": "charged_cost_milli",
            "type": "2"
        }
    ],
    "page": 1,
    "size": 20,
    "appkey": "your_appkey",
    "ts": 1756296558764,
    "sign": "your_signature"
}'
```

**计算类指标及公式：**

*费率指标*
- 千次展示价格：`CPM` = 花费 ÷ 展示量 × 1000
- 单次点击价格：`CPC` = 花费 ÷ 点击量  
- 各类成本指标：`cost_per_xxx` = 花费 ÷ 对应转化数

*转化率指标*
- 点击率：`CTR` = 点击量 ÷ 展示量
- 各类转化率：`xxx_rate` = 转化数 ÷ 点击量

*ROI指标*  
- ROI类：`xxx_roi` = 收入金额 ÷ 花费
